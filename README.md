# React Component Contact Portal

A modular single-page web interface built with React and Vite, demonstrating reusable component architecture, controlled form state management, and real-time user submission feedback.

## Features
- **Modular Component Architecture:** Separated into clean, reusable `Header`, `ContactForm`, and `Footer` JSX components.
- **Controlled State & Validation:** Managed form inputs and submission state using React Hooks (`useState`) with instant UI confirmation alerts.
- **Fast Vite Build Setup:** Configured with Vite for rapid hot-module replacement and optimized production bundling.
